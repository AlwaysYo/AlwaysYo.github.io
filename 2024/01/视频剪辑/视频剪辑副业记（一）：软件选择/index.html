    视频剪辑副业记（一）：软件选择

    剪辑软件说到底只是一个工具， 只要使用者可以剪出好的片子，就是一个好的软件。
    但是，不管什么样的软件，我们都需要花费相等同的时间去学习，所以开始我会选择更加专业的软件去学习。
    基于软件的专业性和泛用性呢，最终选择：

    • Adobe Premiere
    • DaVinci Resolve

    家用剪辑软件

    常见软件：

    1. 绘声绘影
    2. 快剪辑
    3. vue(手机)
    4. iMovie

    适用于快速制作动态相册，简易短视频；炫酷的专场和效果比专业的软件更容易实现；
    :::tips
    **评价：**不够精细，制作的的内容偏简单，有上限；无法胜任更复杂的视频编辑和后期制作
    **结论：**不在选择范围， 放弃
    :::

    Vegas & Edius

    Vegas

    软件介绍：
    Vegas 是一款针对音频、视频剪辑、合成和制作的专业软件。它最初由 Sonic Foundry 公司开发，后被 Sony Creative Software 公司收购，现在由 Magix 公司拥有和开发。Vegas 提供了一整套全面的音频、视频编辑、特效合成、颜色校正和输出工具，被广泛应用于广播、电影、电视、音乐录制等多个领域。
    应用场景：
    Vegas 更多用于音乐视频、广告和独立电影等项目。它提供了广泛的视频和音频编辑工具，同时还具有智能工具，如稳定器和图片插入等，适用于需要快速轻松完成复杂项目的用户。

    Edius

    软件介绍：
    Edius 是一款视频编辑软件，它由日本公司 Canopus（现在为Grass Valley）开发。它提供了一种非常快速、高效的方式来编辑和处理各种类型的视频内容，包括高分辨率、HDR、4K和8K视频。
    Edius 支持多种文件格式，包括 AVCHD、HDV、DV、MPEG-2、H.264、XDCAM、XAVC、ProRes 等，还可以直接从许多摄像机和录制设备导入视频。同时，Edius的实时性能比其他大多数视频编辑软件更好，使其成为专业视频编辑人员和广播电视制作人员的首选之一。
    Edius 配备了一套强大的工具和功能，包括色彩校正、音频混合、字幕、特效、转场和稳定器等。此外，它还可以与其他视频编辑软件和硬件配件集成，例如Adobe Premiere Pro、Avid Media Composer和Blackmagic Design DaVinci Resolve等。
    Edius 可以剪辑，可以调色，还可以加一些花字的包装，但是就是属于什么都能做， 但是什么都做不太好的这样的一个软件。
    应用场景：
    Edius 主要用于广播电视、新闻、影院和活动视频等领域。它可以处理各种文件格式和分辨率，支持多摄像机编辑和实时性能出色，适合需要快速高效完成项目的专业人士。
    :::tips
    **评价：**这两个软件和其他软件的交互不太好， 比如特效软件，专业的调色软件等。
    **结论：**不是优先选择
    :::

    Final Cut Pro

    Final Cut Pro 7

    软件介绍：
    Final Cut Pro 7 是由苹果公司开发的专业视频编辑软件，于2009年发布，它是Final Cut Pro系列软件中的一个版本。Final Cut Pro 7在业内得到了广泛的认可和应用，成为了电影、电视和广告行业中最受欢迎的视频编辑软件之一，它拥有诸多先进的特性和功能，能够满足各种类型和难度的视频制作需求
    应用场景：
    电影、电视和广告行业
    :::tips
    **评价：**Final Cut Pro 7 是视频剪辑中想当稳定的一个软件，也是最优的选择。但是目前已经跟不上时代了，苹果官方已经抛弃它了， 最新的苹果系统已经装不上这个软件了，而且这个软件最高支持的内存只到 4G, 如果使用尺寸大一点的图片（3K 或 4k）,这个软件就会崩溃。也希望苹果公司可以出一款基于 Final Cut Pro 7 升级出来的剪辑软件。
    :::

    Final Cut Pro X

    软件介绍：
    Final Cut Pro X 是一款由苹果公司开发的专业视频编辑软件。它与苹果的Mac OS操作系统完全兼容，具有直观的用户界面、优秀的性能和非常高的剪辑效率。
    应用场景：
    适用于电影制作、电视广告、音乐视频、独立电影等各种类型的视频制作项目。
    :::tips
    评价： Final Cut Pro X 开创了一种新的剪辑形式，首创了磁性时间线，操作方式和传统的软件都不一样，所以这个是它的一个优势，也是它的一个劣势；由于操作方式和传统的软件不一样，也就意味着它和其他软件的交互能力就不行。另外一点呢，它是不能在软件里直接出声音的 OMF 和 AAF 这样的工程框架，常规功能缺失。
    当然，如果你真的用的特别习惯，特别顺手，并且一个项目就在这一个软件中完成，那它是完全没有问题的， 这是一个非常专业的软件， 而且插件特别强大
    :::

    Adobe Premiere

    软件介绍：
    Premiere 具有丰富的功能和工具，可以完成非常复杂的视频编辑任务。它支持多种视频格式，如AVC-Intra、MOV、AVCHD、MXF等，以及各种音频和图像格式。用户可以将不同类型的素材导入到Premiere中，对其进行剪切、调整、变换、合并等操作来实现自己所需的剪辑效果，并且可以通过动态链接技术与其他Adobe软件进行无缝衔接，如与After Effects结合使用来实现更高级的特效和动画处理。
    除此之外，Premiere 还拥有强大的音频处理和调整功能，如音频混合、降噪、音量调整等，能够让用户轻松地控制视频的音频部分。另外，Premiere还支持多摄像机角度编辑、色彩校正、字幕添加、运动图形等高级特性，以及动态字幕、动态图表、3D立体字等创新特性。
    应用场景：
    广泛应用于电影、电视、网络视频等各个领域的视频制作中。
    :::tips
    **评价：**Premiere 会一直进步，拥有新时代的东西，也有很强大的插件群，该有的功能全都有，也拥有很好的软件生态系统，可以与其他Adobe软件进行无缝衔接，让专业流程变得更加顺畅。但是剪辑过程中极容易崩溃，和高/底版本文件协作不方便。
    :::

    Avid Media Composer（硬件公司产品）

    软件介绍：
    Avid Media Composer是一款专业的视频编辑软件，由美国Avid Technology公司开发。它被广泛用于电影、电视、广告、音乐视频等各种视频制作领域，并且被誉为世界上最著名的视频编辑软件之一。
    Avid Media Composer拥有许多强大的功能和工具，如精确的剪辑、音频混合、色彩校正、特效、字幕编辑等，可以帮助用户完成非常复杂的视频编辑任务。它还支持多种视频格式，如MXF、MOV、AVC-Intra等，以及多个分辨率，能够很好地满足不同分辨率的制作需求。另外，它还支持多平台操作系统，如Windows、MacOS等。
    除此之外，Avid Media Composer还拥有先进的“基于流”的剪辑技术，可以同时处理video、audio、fx等多路信号，从而提高了编辑效率和精度。而且，Avid Media Composer还提供了与其他Avid产品的无缝集成，如Avid Interplay（用于媒体生产管理）、Avid ISIS（用于存储管理）等，使得整个视频制作过程更加高效和协同。
    总的来说，Avid Media Composer是一款功能强大、稳定性高、易于使用的专业视频编辑软件，被广泛应用于电影、电视、广告等行业，尤其是大型制作公司和电影工作室。
    应用场景：
    被广泛应用于电影、电视、广告等行业，尤其是大型制作公司和电影工作室。
    :::tips
    **评价：**是一个专业的电影剪辑软件，多用于大型项目，稳定性特别好，在国内市场用的特别少。它有一套自己的专业流程，需要把所有文件统一成这个软件认识的格式，它才能很顺畅的工作，个人剪辑和小团队就不用考虑这个软件了。
    :::

    DaVinci Resolve（硬件公司产品）

    软件介绍：
    DaVinci Resolve是一款由Blackmagic Design公司开发的专业视频编辑软件，已经成为世界上最强大的视频后期制作软件之一。它被广泛用于电影、电视、广告等各种视频制作领域。
    DaVinci Resolve提供了全套的视频后期制作工具，如剪辑、色彩校正、音频混音、特效、字幕等，可以满足从初步编辑到最终制作的所有需求。它使用了独特的节点编辑方式，使得调整和修改色彩非常方便和直观。
    与此同时，DaVinci Resolve支持多个分辨率和格式，包括高清、4K和超高清等，并具有自动代理文件生成功能，使得在不同的设备上进行视频编辑和处理更加方便。
    另外，DaVinci Resolve还有强大的音频编辑功能，能够完美地处理音频问题，例如移除噪声、去除回声等。而且，它还能够与其他软件和硬件进行集成，如Adobe Premiere Pro、Final Cut Pro X等，以及Avid控制表面和逐帧控制器等，从而极大地提高了工作效率。
    DaVinci Resolve是一款功能强大、性能卓越、易于操作的视频编辑软件，非常适合需要高质量制作和处理视频的用户。它被公认为视频后期制作领域中的佼佼者，而且也逐渐成为了一些中小型制作公司或个人制作者的首选软件。
    :::tips
    **评价：**在调色领域非常有名的一个软件，调色公司几乎都会装这个软件，随着版本的更迭， 截至目前，达芬奇18，可以剪辑、调色、合成、混音。软件中的每一个功能都做到了世界级
    :::
