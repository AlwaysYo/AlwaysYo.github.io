    Git 标签

    标签

    tag就是一个让人容易记住的有意义的名字，它跟某个commit绑在一起。

    新建一个标签

    命令git tag <tagname>用于新建一个标签，默认为HEAD，也可以指定一个commit id。

    指定标签信息

    you can use like this: git tag -a <tagname> -m "say something..."

    PGP签名标签

    you can use like this: git tag -s <tagname> -m "say something..."
