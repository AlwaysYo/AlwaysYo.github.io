    Docker 部署方法总结

    Docker 简介

    Docker 是什么？

    基本概念

    • 镜像（image）： 相当于一个 root 文件系统
    • 容器（container）： 是镜像运行的实体（镜像和容器的关系就像是面向对象编程中的类和实例一样）
    • 仓库（repository）: 可看作是一个代码控制中心， 用来保存镜像
