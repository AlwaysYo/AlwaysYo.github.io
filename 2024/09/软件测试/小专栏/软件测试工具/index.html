    软件测试工具

    自动化测试

    **需求：**通过 url 或文件导入项目的接口

    需求扩展：

    1. 支持导入功能

      • 导入的接口支持 mock （可自定义勾选）

    2. 支持导出功能 （可自定义勾选）

      • 可导出为 json 文件
      • 可导出为 代码 或 **.py 文件（对接接口自动化的 data 层文件）

    3. 可以对系统的接口进行监听

      • 接口变动邮件通知
      • 接口变动可实时更新 data 层的接口信息，更新后上传 git 并邮件通知

    性能测试小工具

    1. 性能测试逐步加压发现瓶颈，逐步加压利用 shell 脚本实现（自动化压测）

    2. 公司需要统一的压力发生平台，能不能试着用 jmeter 的集群模式去搭建一个

    其他工具

    1. 修改文件大小，可自定义
    2. 数据插入 ==> 流量回放 ？？？？
    3. 如何开展混沌工程， 如何开发混沌工程用到的工具，包括二次开发 chaos-mesh 的经验。
    4. 如何根据 Docker 和 K8S 的原理构建对应的工具，包括在 K8S 中构建 mock server 平台，jenkins 与 K8S 打通 CI/CD 流水线，
    5. 如何利用普罗米修斯搭建监控平台，如何利用 K8S 的 list and watch 补充普罗米修斯能力上的不足等。
    6. 如何开展稳定性与性能测试，如何在 K8S 中构建 分布式压测工具。
    7. 当 K8S 与大数据结合在一起时，都有哪些测试点，我们应该如何开展测试活动。
